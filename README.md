# - MoviePolice -

Implement a web application that lets the user write and scroll through reviews.

## Initial structure:

- [x] React frontend w/Husky, prettier and Vite setup
- [x] Typescript to avoid data-type errors
- [x] Hono backend
- [x] React router
- [x] MongoDB
- [x] Dynamic title in head in index.html

## Final touches:

- [x] Editorial functionality
- [x] Add users; `admin`, `user` and `guest`
- - [x] Admin: Ability to delete, edit, and add.
- - [x] User: Ability to read, add, delete and edit personal posts
- - [x] Guest: Read only (Both movies and comments)
